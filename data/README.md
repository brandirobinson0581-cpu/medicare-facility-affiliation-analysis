# Data

`Facility_Affiliation.csv.gz` is the compressed CMS Facility Affiliation file used in the executed notebook. The file is read directly by pandas, so it should not be decompressed before running the analysis.

Official source: [Centers for Medicare & Medicaid Services, Facility Affiliation Data](https://data.cms.gov/provider-data/dataset/27ea-46a8), accessed September 12, 2026.
